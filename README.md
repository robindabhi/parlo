# Parlo — free family language app

A Duolingo-style language app that runs entirely in the browser. No accounts, no servers, no cost.

Courses: Spanish, French, German, Italian and Latin (taught in English), plus English taught in Hindi and English taught in Gujarati.

## Put it online for free (GitHub Pages)
1. Create a free GitHub repository (for example `parlo`).
2. Upload every file in this folder to it.
3. In the repo: Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. After a minute it is live at `https://<your-username>.github.io/parlo/`.

## Install on phones
- Android (Chrome): open the link → menu ⋮ → "Add to Home screen" / "Install app".
- iPhone/iPad (Safari): open the link → Share → "Add to Home Screen".
It then opens full-screen like a normal app and works offline after the first visit.

## Notes
- Progress is stored on each device. Use Me → "Backup & move devices" to copy progress between devices.
- Listening uses the device's built-in voices. Speaking practice uses the browser's speech recognition (Chrome, Edge, Safari).
